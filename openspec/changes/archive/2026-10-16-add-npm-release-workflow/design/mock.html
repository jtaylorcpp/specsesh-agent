add-npm-release-workflow: from tag to npm

FAKE DATA Versions, timings and output are examples.

1. Cutting a release

$ git tag v0.2.0 && git push origin v0.2.0 To github.com:jtaylorcpp/specsesh-agent.git * [new tag] v0.2.0 -> v0.2.0

2. The release job (permissions: id-token write, contents read)

  1. ✓ pnpm install --frozen-lockfile
  2. ✓ pnpm check
  3. ✓ pnpm test
  4. ✓ pnpm pack:check
  5. ✓ release-check v0.2.0 → latest
  6. ✓ pnpm pack × 2 → release/specsesh-agent-0.2.0.tgz, release/specsesh-0.2.0.tgz
  7. ✓ release-check v0.2.0 --packed release/specsesh-0.2.0.tgz
  8. ✓ npm publish specsesh-agent-0.2.0.tgz --access public --provenance --tag latest
  9. ✓ npm publish specsesh-0.2.0.tgz --access public --provenance --tag latest

3. A refused release

$ node scripts/release-check.mjs v0.2.1 tag v0.2.1 is not v0.2.0 $ echo $? 1 $ node scripts/release-check.mjs v0.3.0-rc.1 next

4. After

$ npm view specsesh@0.2.0 dependencies { '@specsesh/agent': '0.2.0', '@earendil-works/pi-ai': '1.1.0', ... } $ npx specsesh@0.2.0 --version specsesh 0.2.0 # npmjs.com shows "Built and signed on GitHub Actions" with the commit and release.yml
