A GitHub Actions workflow that, on a `v<version>` tag, checks, packs and publishes `@specsesh/agent` then `specsesh` to public npm through trusted publishing (OIDC) with provenance, after a release check holds the tag, both manifest versions and the packed dependency to one version. Follows add-specsesh-package (slice 3 of add-specsesh-command's slices.md). The manual steps (trusted publisher on npmjs.com, first publish) go in design.md, not tasks.
