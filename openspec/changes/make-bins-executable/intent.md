From a fresh clone, `pnpm install && pnpm build` leaves `packages/agent/dist/bin/*.js` without the execute bit (tsc never sets it), so running a bin directly, or through a link to it, fails with "Permission denied". Make the build mark every bin executable, keep `packages/specsesh/bin/specsesh.js` committed as executable, and send command-line users of `@specsesh/agent`'s README to `specsesh`, since a global install of `@specsesh/agent` alone lacks its optional Node peers.
